# Roadmap

Machine-readable copy: [roadmap/milestones.json](roadmap/milestones.json). GitHub milestones mirror it.
Each item closes on evidence, not on merging code. See [PLAN.md](../PLAN.md) for the acceptance column.

| Milestone | Result | Stage today |
|---|---|---|
| 1. Clean-setup launch | A game queued from the phone starts on a Deck from a clean install, from your own storage | implemented, automated; not yet measured on the current revision |
| 2. Failure to fix | One real failure report is reproduced and fixed with a regression test | no real report yet |
| 3. Startup comparison | Cold unprofiled, cold profiled and warm runs compared with byte counts and times | not started on current code |
| 4. Qualified release | Release candidate tested as shipped, with checksums and notices | v1.0.0 predates own-storage |
| 5. Discoverable | A reader can find, try and contribute in minutes | landing page live |
| 6. Outside feedback | A report from an unaffiliated tester | none yet |
