# Reporting security issues

Use the repository's [private vulnerability reporting form](https://github.com/hffgzktbcc-blip/deckstream/security/advisories/new). Include the affected revision, component, conditions and minimal reproduction. Use mock values or redacted excerpts for sensitive configuration.

DeckStream has a shared queue credential, storage credentials, and optional signing trust. Report suspected issues involving credential handling, storage relay access, job authorization or update integrity privately. Use public issues for routine setup and launch failures.
