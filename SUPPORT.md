# Getting help

- **Questions and setup help:** [Discussions → Q&A](https://github.com/hffgzktbcc-blip/deckstream/discussions/categories/q-a).
  Remove credentials, tokens and private hosts first.
- **A launch failed or was slow on a Steam Deck:** the [launch report form](https://github.com/hffgzktbcc-blip/deckstream/issues/new?template=launch-report.yml).
  Start with `doctor.py` and [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
- **Something else is broken:** a [bug report](https://github.com/hffgzktbcc-blip/deckstream/issues/new?template=bug.yml).
- **Security problem:** the [private form](https://github.com/hffgzktbcc-blip/deckstream/security/advisories/new), never a public issue. See [SECURITY.md](SECURITY.md).

DeckStream is maintained by volunteers, so replies can take a few days. It does not provide or
help find games.
